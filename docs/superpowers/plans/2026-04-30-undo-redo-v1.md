# Undo/Redo v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add fixed-size undo/redo for primitive editor edits and expose it through command prompt commands.

**Architecture:** `TideEditor` stores undo and redo stacks of small edit actions. Public edit functions record inverse actions; undo/redo apply actions through internal no-history helpers to avoid recursive recording. The app command dispatcher maps `undo` and `redo` to the editor APIs.

**Tech Stack:** C11, CMake, CTest, existing `TideEditor` and `TideBuffer` primitives.

---

## File Structure

- `include/tide/editor.h`: add edit action types, fixed history stacks, and `tide_editor_undo()` / `tide_editor_redo()`.
- `src/editor.c`: record inverse actions for edits, apply history actions, clear redo on new edits, clear search on text changes.
- `tests/test_editor.c`: cover character, deletion, newline, redo clearing, and search clearing behavior.
- `src/app.c`: dispatch `undo` and `redo` commands.
- `tests/test_app.c`: cover command-level undo/redo.
- `README.md`: document undo/redo commands.

```c
#define TIDE_EDITOR_HISTORY_CAPACITY 256

typedef enum TideEditorEditActionKind {
    TIDE_EDITOR_ACTION_INSERT_CHAR = 1,
    TIDE_EDITOR_ACTION_DELETE_CHAR,
    TIDE_EDITOR_ACTION_INSERT_NEWLINE,
    TIDE_EDITOR_ACTION_DELETE_NEWLINE
} TideEditorEditActionKind;

typedef struct TideEditorEditAction {
    TideEditorEditActionKind kind;
    TideBufferPosition position;
    char ch;
} TideEditorEditAction;
```

Add fields to `TideEditor`:

```c
    TideEditorEditAction undo_stack[TIDE_EDITOR_HISTORY_CAPACITY];
    size_t undo_count;
    TideEditorEditAction redo_stack[TIDE_EDITOR_HISTORY_CAPACITY];
    size_t redo_count;
```

Add declarations:

```c
TideStatus tide_editor_undo(TideEditor *editor);
TideStatus tide_editor_redo(TideEditor *editor);
```

- [ ] **Step 4: Implement history behavior**

In `src/editor.c`:

- Initialize `undo_count` and `redo_count` to `0` in `tide_editor_init()`.
- Add a private stack push helper that drops the oldest action when a stack is full.
- Add private no-history action application for insert char, delete char, insert newline, and delete newline.
- Update `tide_editor_insert_char()`, `tide_editor_insert_newline()`, and `tide_editor_backspace()` to push inverse actions only after successful changes.
- Clear redo after every new normal edit.
- Clear search state after successful edits, undo, and redo.
- `tide_editor_undo()` pops undo, applies it, and pushes the produced inverse onto redo. If empty, set status `nothing to undo`.
- `tide_editor_redo()` pops redo, applies it, and pushes the produced inverse onto undo. If empty, set status `nothing to redo`.
