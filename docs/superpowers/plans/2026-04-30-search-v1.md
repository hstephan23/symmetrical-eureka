# Search v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add literal single-buffer search through command prompt commands.

**Architecture:** `TideEditor` owns search query and current match state. The app command dispatcher maps `find <text>`, `next`, and `prev` to editor search APIs. The renderer highlights the current visible match by applying reverse style to matching cells.

**Tech Stack:** C11, CMake, CTest, existing `TideBuffer`, `TideEditor`, and virtual screen renderer.

---

## File Structure

- `include/tide/editor.h`: add search state fields and search APIs.
- `src/editor.c`: implement literal forward/backward search with wraparound.
- `tests/test_editor.c`: cover search movement, wraparound, and no-match status.
- `src/app.c`: dispatch `find`, `next`, and `prev` commands.
- `tests/test_app.c`: cover command-level search behavior.
- `src/editor_render.c`: highlight the active match.
- `tests/test_editor_render.c`: cover highlight styling.
- `README.md`: document search commands.

```c
{
    for (size_t i = 0; text[i] != '\0'; ++i) {
        if (text[i] == '\n') {
            TIDE_ASSERT(tide_editor_insert_newline(editor) == TIDE_OK);
        } else {
            TIDE_ASSERT(tide_editor_insert_char(editor, text[i]) == TIDE_OK);
        }
    }
}

{

    TideEditor editor;

    TIDE_ASSERT(tide_buffer_init(&buffer) == TIDE_OK);
```

- [ ] **Step 4: Implement editor search**

In `tide_editor_init()`, initialize search fields:

```c
    editor->search_query[0] = '\0';
    editor->search_query_length = 0;
    editor->search_match = (TideBufferPosition){0, 0};
    editor->search_match_length = 0;
    editor->search_has_match = 0;
```

Implement literal, case-sensitive search in `src/editor.c`. Use bounded line scanning with `memcmp()` so matches can be found forward and backward without regex or heap allocation.

Required behavior:

- `tide_editor_find(editor, query)`:
  - If `query` is empty, set status to `search query required`, clear match, and return `TIDE_OK`.
  - Search from `editor->cursor` through the end, then wrap from the top to the original cursor.
  - On match, store query, match position, and match length, move cursor to match, clear status, and return `TIDE_OK`.
  - On no match, clear active query and match, keep cursor unchanged, set status to `no match: <query>`, and return `TIDE_OK`.
- `tide_editor_find_next(editor)`:
  - If no active query, set status to `no active search` and return `TIDE_OK`.
  - Search from one column after the current match start with wraparound.
- `tide_editor_find_previous(editor)`:
  - If no active query, set status to `no active search` and return `TIDE_OK`.
  - Search backward from before the current match start with wraparound.

In `src/app.c`, add a small whitespace helper:

```c
static const char *skip_command_spaces(const char *text)
{
    while (*text == ' ' || *text == '\t') {
        text++;
    }
    return text;
}
```

In `tide_app_execute_editor_command()` before the unknown-command branch:

```c
    if (strncmp(command, "find", 4) == 0 && (command[4] == '\0' || command[4] == ' ' || command[4] == '\t')) {
        const char *query = skip_command_spaces(command + 4);
        return tide_editor_find(editor, query);
    }

    if (strcmp(command, "next") == 0) {
        return tide_editor_find_next(editor);
    }

    if (strcmp(command, "prev") == 0) {
        return tide_editor_find_previous(editor);
```
